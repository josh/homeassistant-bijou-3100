# Bijou 3100

Media player control plus subwoofer, headphone, and equalizer switches and diagnostic sensors for the AudioControl Bijou 3100 amplifier.

## Installation

Use [HACS](https://hacs.xyz), or download the latest [release](https://github.com/josh/homeassistant-bijou-3100/releases/latest) and copy `custom_components/bijou_3100` into your `config/custom_components/` directory.
